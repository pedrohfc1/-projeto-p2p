# PeeTwoPee — identidade original
Dois P em sentidos opostos formam uma ligação entre pares; os pontos âmbar representam as pessoas. Fundo #101b2c, menta #53e0c1, azul #6a9fff, âmbar #f8ca75. Fontes SVG editáveis, tipografia Segoe UI/DejaVu Sans do sistema. Exportações PNG e ICO em múltiplas resoluções. Nenhum recurso de terceiros foi copiado. Arte original sob a licença MIT deste projeto.
