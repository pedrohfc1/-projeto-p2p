# Sons do PeeTwoPee

Oito efeitos originais para conexão, saída, participantes e compartilhamento de tela. Foram sintetizados com ondas senoidais, harmônico de baixa intensidade e envelopes de ataque e saída. Os arquivos WAV são mono a 16 kHz, com menos de 250 ms por efeito, e seguem a licença do projeto.
